# Журнал проверки выполнения требований

Актуальное дополнение13 октября: E04 shared collectors/snapshots реализованы и проверены в Ubuntu WSL2, раздел13 ниже; E03 auth/transport — раздел12; исторические E01/E02 записи описывают своё состояние на момент проверки и не переписаны.

Дата исходного снимка: 12 октября 2026 года, Europe/Moscow. Исходное окружение подготовки: Windows, PowerShell7.6.5, Python3 без Go/Agent. В E01 добавлен переносимый Go1.27.2 и код с Windows/cgo проверками; позднее Ubuntu WSL2 amd64 и arm64 cross/QEMU проверены отдельно в разделе9, native ARM gate перенесён в E12 (раздел10), E01 закрыт по уточнённым критериям. Никакой реальный сервер этой работой не изменялся.

## 1. Значения статусов

«Согласовано» — AFR/ASEC и пакет Р01–Р25 приняты пользователем. «Специфицировано» — техническая детализация записана; «частично» указывает конкретный gate. «Реализовано» — существует конкретный код/миграция/путь с build/evidence. «Проверено» — конкретная проверка поведения на указанном окружении. Частичные E01-записи не закрывают полную приёмку AFR/ASEC; Git commit отсутствует, состояние фиксируется SHA256 исходных файлов в evidence. D-* ниже проверяют документы и не меняют runtime-статусы AFR/ASEC.

Для новой записи обязательны дата, окружение/ОС/архитектура/ядро/Go/SQLite/GPU при применимости, версия артефакта, точная команда или воспроизводимые шаги, ожидаемый результат, фактический результат/лог и ограничение. «Не проверено» не означает успех; заглушки не закрывают оборудование/systemd/security gates. Процедуры V-* определены в [плане](<9. План реализации.md>), ограничения — в [готовности](<10. Противоречия и готовность.md>).
