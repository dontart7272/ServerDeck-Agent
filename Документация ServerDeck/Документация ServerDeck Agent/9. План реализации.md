# План реализации полного ServerDeck Agent

12 октября 2026 года. Весь объём AFR-001–AFR-072 и ASEC-001–ASEC-031 сохраняется; этапы не являются сокращением продукта. Исходно все этапы не начаты; текущий E01 проверен на Windows и Ubuntu22.04 WSL2 amd64 (cgo/vet/test/race/smoke); arm64 cgo cross-build/ELF/QEMU и воспроизводимость получены. По решению пользователя 13 октября 2026 native ARM smoke/tests/race перенесены в E12; E01 закрыт по уточнённым критериям. ARM64 пока экспериментален, нативная поддержка не подтверждена. E02 закрыт в offline-границах по V-STORE/V-AUDIT и Ubuntu WSL2 проверкам. E03 auth/transport закрыт по отдельному поручению в Ubuntu WSL2: [E03 evidence](<../../agent/evidence/E03-wsl-2026-10-13/README.md>), [границы реализации](<../../agent/AUTH-TRANSPORT.md>). E04–E12 не начаты. [E02 evidence](<../../agent/evidence/E02-wsl-2026-10-13/README.md>). См. [команды и ограничения E01](<../../agent/BUILD.md>). Наличие схем/плана не означает прохождение exit gate. [Трассировка каждого требования](<11. Журнал проверки требований.md>), [препятствия](<10. Противоречия и готовность.md>), [архитектура](<8. Архитектура и обслуживание.md>).

## 2. Проверяемые процедуры

Каждая процедура после реализации получает exact command/test id, fixture digest, окружение, дату и фактический результат в журнале. E01 V-BUILD/V-CONTRACT выполнены в предусмотренных для offline-каркаса границах; остальные части процедур проверяются после реализации соответствующих функций. Native ARM V-BUILD перенесён в E12; точные Windows/WSL evidence и открытые критерии приведены в журнале. V-STORE/V-AUDIT E02 проверены в границах critical.db/compiled effects/offline maintenance; events/history/full update recovery остаются зависимым этапам. V-AUTH/V-CONTRACT E03 проверены для включённых HTTPS/WSS/local transports; файлы/Android trust UX и прочие ещё отсутствующие адаптеры остаются V-FILE/V-CLIENT/E12 и не объявляются проверенными. Остальные процедуры не объявляются выполненными. Для destructive/crash/disk tests — только изолированные VM/temp mounts/данные, не пользовательский VPS без отдельной авторизации.

## 3. Вход в первый этап

Документация достаточна для E01: нет необходимости повторно согласовывать принятые продуктовые развилки. Module path `serverdeck.local/agent` подтверждён пользователем, Go1.27.2 подготовлен переносимо в корневой `.tools/go`. Windows GCC16.1.0/cgo доступен; Git checkout отсутствует. E01-код и Windows-проверки существуют. Ubuntu-22.04 WSL2 теперь подготовлена и проверена отдельно от docker-desktop: amd64 cgo build/smoke/vet/test/race, arm64 cgo cross-build/ELF/QEMU, builder lock и byte-identical rebuild получены. E01 закрыт по уточнённым критериям. По решению пользователя 13 октября 2026 из-за отсутствия ARM-стенда native ARM smoke/vet/test/race с собственной native cgo цепочкой перенесены в E12. Эмуляция их не заменяет; непроверенная нативная ARM-поддержка не объявляется. Перенос снимает ARM-блокировку входа в E02, но не запускает E02 автоматически.

BLOCK-FS препятствует допуску части E08, TECH-IPC — external UID части E09, trusted release keys/host/GPU стенды — E11/E12. Они не мешают независимому каркасу, storage и auth. Ни один unresolved gate нельзя спрятать за «поддержка есть» или mocked тестом.

## 6. Результат E04 — 13 октября 2026

E04 реализован и проверен в Ubuntu-22.04 WSL2 amd64 для общего read-only Linux-сбора system/CPU/RAM/FS/network/processes и защищённых snapshot/process queries/WSS. [Технические границы](<../../agent/METRICS.md>), [воспроизведение и evidence](<../../agent/evidence/E04-wsl-2026-10-13/README.md>), журнал раздел13. V-METRIC: известные точки/формулы, reset/hotplug/PID reuse/clock segment, потеря прав и last-good, lease expiry, независимость от клиентов/аудита, bounded hung sources/statfs, stable pages/scope/TTL, ordinary/root и native read-only contracts прошли. Частоты2/5/15/60с проверены на точных scheduler boundaries; real2с collection и WSS delivery дополнительно проверены живыми таймерами.

Gofmt/vet/test/race, amd64 compiled CLI/TLS/WSS/local smoke и arm64 cgo cross-build/ELF выполнены. E04 закрыт для этих adapters и процедур; это не закрывает полную матрицу аппаратных датчиков/ОС, native ARM или production systemd watchdog/ресурсный soak, которые остаются E11/E12. Conditional unavailable fields не подменены нулём. E05 (history/events) ещё не реализован и автоматически не запускается.
