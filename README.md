Документы клиента включены как нормативный контекст Agent и для сохранения ссылок.
Бинарники и локальное окружение сборки в Git не включаются.

Evidence фиксируют исторические проверенные снимки. Их контрольные суммы документов
относятся к моменту проверки; последующие изменения документации, включая сведения о Git,
не переписывают исторические результаты. Поддержка всей серверной матрицы и native ARM
пока не подтверждена; точные ограничения указаны в BUILD.md и журнале.
